## 项目简介

Hermes-doc-cn 是 Hermes Agent 的非官方中文翻译文档，目标是降低中文用户理解和使用 Hermes Agent 的门槛。

## 价值

这个项目不只是翻译页面，更重要的是把工具的安装、配置、功能特性和实践方法组织成更容易阅读的中文资料。
